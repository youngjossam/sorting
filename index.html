작은 수부터 차례대로 놓으려면?

같은 숫자를 선택 정렬과 버블 정렬로 나란히 정렬해 보세요.

① 선택 정렬

남은 범위에서 가장 작은 수를 골라 맨 앞과 바꿔요.

② 버블 정렬

이웃한 두 수를 비교해 큰 수를 오른쪽으로 보내요.

비교한 두 수현재 최솟값 후보방금 자리 교환자리 확정

3분 탐구 미션

1. 작은 수를 고르기 vs 큰 수를 밀기

6개의 섞인 자료로 시작하세요. 선택 정렬은 어느 쪽부터, 버블 정렬은 어느 쪽부터 자리가 확정되나요?

2. 이미 정렬되어 있다면?

‘이미 정렬된 자료’로 바꾸세요. 어느 정렬이 먼저 끝나나요? 비교와 교환 횟수를 따로 살펴보세요.

3. 거꾸로 정렬되어 있다면?

‘거꾸로 정렬된 자료’로 바꾸세요. 이웃끼리만 바꾸는 버블 정렬의 교환 횟수는 어떻게 되나요?

실험 규칙: 오름차순 정렬입니다. ‘한 단계’는 숫자 두 개 비교 또는 자리 교환입니다. 두 알고리즘의 한 단계가 반드시 같은 종류의 작업은 아닙니다. 실행 속도보다 비교 횟수와 교환 횟수를 구분해 관찰하세요.

이번 구현: 선택 정렬은 최솟값이 이미 제자리에 있으면 교환하지 않습니다. 버블 정렬은 한 회전 동안 교환이 없으면 일찍 종료합니다. 비교는 두 자료값의 비교만, 교환은 두 자료의 자리를 맞바꾸는 작업만 셉니다.

파이썬 코드와 핵심 원리 보기

선택 정렬 · 최솟값 선택

def selection_sort(data):
    n = len(data)
    for i in range(n - 1):
        min_idx = i
        for j in range(i + 1, n):
            if data[j] < data[min_idx]:
                min_idx = j
        if min_idx != i:
            data[i], data[min_idx] = data[min_idx], data[i]
    return data

버블 정렬 · 이웃끼리 비교

def bubble_sort(data):
    n = len(data)
    for end in range(n - 1, 0, -1):
        swapped = False
        for j in range(end):
            if data[j] > data[j + 1]:
                data[j], data[j + 1] = data[j + 1], data[j]
                swapped = True
        if not swapped:
            break
    return data

선택 정렬의 비교 횟수는 n(n−1)/2회입니다. 이 버블 정렬은 이미 정렬된 자료에서 n−1회만 비교하지만, 최악의 경우 n(n−1)/2회 비교합니다. 최악의 시간 복잡도는 둘 다 O(n²)입니다.

자료 개수·처음 상태를 바꾸면 새 실험이 시작됩니다. 한쪽이 먼저 끝나면 다른 쪽만 계속 진행합니다. 외부 연결 없이 사용할 수 있는 수업용 페이지입니다.
